# 📊 Datos del proyecto

Esta carpeta contiene información complementaria relacionada con los datos utilizados en el proyecto GOLDEN GYM.

Los datos principales del proyecto se encuentran en:

`sql/04_insertar_datos.sql`

## Datos utilizados

El proyecto contiene:

- 100 clientes.
- 100 membresías.
- 70 membresías activas.
- 30 membresías vencidas.
- 3 planes de membresía.
- 1 sede.
- 4 entrenadores.

## Fuente de los datos

Los datos utilizados son **datos simulados creados con fines educativos y de demostración**, para construir un escenario realista de análisis de un gimnasio.

No se utilizan datos personales reales.

## Objetivo

Los datos permiten realizar análisis sobre:

- Clientes.
- Membresías.
- Planes.
- Ingresos.
- Estado de las membresías.
- Comportamiento de los clientes.
